Backprop on the JAX backend: `jax.grad`, `jax.jacrev` and `jax.jit` apply to circuits compiled with `compile_circuit`, and the gradients equal the adjoint and parameter-shift results. `parameter_map(circuit)` maps one value per symbol to the compiled slot array, so a shared symbol gets the sum of its slots' gradients. `JaxBackend.adjoint_jacobian` now runs the compiled program, so repeated calls on one circuit structure compile once.
