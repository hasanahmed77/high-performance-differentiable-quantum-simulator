A JAX backend, `JaxBackend` (`pip install "ketjet[jax]"`), that returns the NumPy backend's results on JAX arrays, in both precisions. Select it with `get_backend("jax")` or `qml.device("ketjet.qubit", backend="jax")`. complex128 needs JAX's 64-bit mode; ketjet raises a clear error instead of silently computing in complex64.
