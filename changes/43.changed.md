The `pennylane` extra now requires PennyLane 0.44.1 or later. PennyLane 0.44.0 can't be imported with current versions of its dependency `diastatic-malt`, so it never worked in a fresh install. CI now tests the lowest supported version of every dependency (NumPy 2.1, PennyLane 0.44.1, JAX 0.10.0, on Python 3.12) and, daily, the latest releases.
