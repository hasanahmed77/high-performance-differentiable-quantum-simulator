A benchmark suite, `python -m benchmarks.run`: single-gate throughput, the QFT, random circuits, a VQE gradient and a batched QML gradient, on the NumPy and JAX backends, CPU or GPU. It follows ADR-0008: it times the first call separately, checks every answer against the NumPy oracle before timing it, runs each case in its own processes, and writes JSON with a record of the machine. The first results are in `benchmarks/results/`.
