The PennyLane device `ketjet.qubit` (`pip install "ketjet[pennylane]"`, then `qml.device("ketjet.qubit", wires=n)`): PennyLane decomposes circuits into ketjet's gates, which run on a ketjet backend; `expval`, `var` and `probs` are computed by ketjet, with seeded shots, shot vectors and `c_dtype` precision. `import ketjet` doesn't import PennyLane.
