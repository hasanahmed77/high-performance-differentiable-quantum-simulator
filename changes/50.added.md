A GPU test suite, `pytest -m gpu tests/gpu`, runs the JAX backend on an NVIDIA GPU and compares it with the CPU: states, expectation values, backprop and adjoint Jacobians, `jax.vmap` batches, `ketjet.qubit` and its seeded samples, and the adjoint method's memory, which stays flat with circuit depth on the GPU too. Getting started has a new "Running on a GPU" section.
