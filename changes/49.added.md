`expval_fn(circuit, observables, diff_method=...)` builds a JAX function of a circuit's symbol values that returns its expectation values. With `diff_method="adjoint"` its gradient is the adjoint method as a `jax.custom_vjp`: memory doesn't grow with circuit depth, and one backward pass serves every observable. `"backprop"` stays the default, because the adjoint method has no forward mode: `jax.jvp` and `jax.jacfwd` raise, while `jax.hessian` works. On JAX 0.10 the memory still grows a little with depth (about 0.4 states per layer, against backprop's 12); JAX 0.11 and later stay flat.
