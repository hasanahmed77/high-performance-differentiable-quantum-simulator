The benchmark suite now also runs PennyLane's `default.qubit` and `lightning.qubit`, Qiskit Aer and Qulacs on the same circuits, on the CPU. Each library gets the same gates and angles through its own API, and every translation is checked against ketjet's NumPy oracle before it's timed. The libraries are in a separate `bench` dependency group (`uv sync --group bench`), and the first comparison, with the cases where ketjet loses, is on the docs' Benchmarks page.
