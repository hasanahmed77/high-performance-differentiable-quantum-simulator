# Getting started

!!! note
    ketjet hasn't been released on PyPI yet. Until v0.1.0, install it from source.

## Requirements

- Python 3.12–3.15
- Linux, macOS or Windows

## Install from source

```bash
git clone https://github.com/hasanahmed77/high-performance-differentiable-quantum-simulator.git
cd high-performance-differentiable-quantum-simulator
pip install .
```

Check the installation:

```python
import ketjet

print(ketjet.__version__)
```
